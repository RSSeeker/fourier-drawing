# 🔄 傅里叶画板 · Fourier Epicycles

手绘图案，用**旋转的圆（傅里叶级数）**把它重新画出来。每个圆代表一个傅里叶系数——半径是幅值、初始相位是辐角、旋转速度是频率——所有圆首尾相接，圆链末端（"画笔"）的运动轨迹就是对你笔迹的傅里叶近似。

## ✨ 功能特性

- **手绘画板**：鼠标/触屏自由绘制，支持多笔画、撤销、清空、笔色/粗细调节，内置「心形」「螺旋」示例
- **多笔画独立动画**：每一笔笔画独立重采样 → 离散傅里叶变换 → 各自的圆轮与轨迹，所有笔画同时转动描画（每笔一种颜色）
- **圆轮可视化**：可开关圆、圆心连线、轨迹、参考线；圈数（1–400）与速度滑杆实时可调；播放/暂停（空格键）/重置
- **轨迹渐隐**：勾选后轨迹从新到旧由亮变暗，拖尾效果
- **闭合路径**：自动把开放笔画"闭合"，消除开放路径周期延拓的吉布斯振荡——动画开头不再出现异常乱甩的直线
- **导出 / 导入参数**：圆参数保存为 JSON（频率 k、半径、初始相位、复系数 + 采样路径），可随时载入复现；导出时可选保存位置
- **两种版本，完全互通**：Windows 单文件 exe 与网页版功能一致，导出文件可互相导入

## 📦 下载与使用

- **Windows 单文件程序**：从 Releases 下载 `fourier-drawing.exe`（约 190 KB，纯 Win32/GDI，只依赖系统 DLL，无第三方库、无需安装），双击即可运行
- **网页版**：下载 `fourier-drawing.html` 用浏览器打开，或直接双击

## 🔨 手动构建（可选）

需要 MinGW-w64（gcc）。在源码目录执行：

```powershell
gcc -O2 -municode -mwindows fourier-drawing.c -o fourier-drawing.exe `
    -lcomctl32 -lcomdlg32 -lgdi32 -luser32
```

自测（无界面，结果写入 `selftest.txt`）：

```powershell
fourier-drawing.exe --selftest
```

## 🖱 使用说明

1. 在左侧画板绘制图案（可画多个笔画），或点击「心形示例 / 螺旋示例」
2. 点击「生成傅里叶动画」——每个笔画被采样 2048 个点并闭合，离散傅里叶变换后按模长取前 M 个系数，每个系数就是一个旋转的圆
3. 观察圆轮描画轨迹；用「圈数」「速度」滑杆调节，勾选「渐隐」查看拖尾效果
4. 「导出参数」保存为 JSON（可选保存位置），之后可「载入参数」复现；网页版也支持把 JSON 拖进窗口导入

## 📄 导出格式

```json
{
  "app": "fourier-drawing",
  "version": 2,
  "strokes": [
    {
      "sampleCount": 2176,      // 动画周期（含闭合返回段）
      "strokeCount": 2048,      // 笔画段样本数（轨迹只在笔画段绘制）
      "circles": [
        { "k": 1, "radius": 50.0, "phase": 0.0, "re": 50.0, "im": 0.0 }
      ],
      "path": [[320.0, 320.0], [321.1, 322.5]]
    }
  ]
}
```

- `k`：频率（正 = 逆时针，负 = 顺时针）；`radius = |c|`、`phase = arg(c)`、`re/im` 为复系数
- 兼容旧版（v1 顶层 `circles` / 无 `strokeCount` 的旧 v2）文件：导入时自动闭合重算

## 🧮 算法原理

1. **重采样**：把笔迹按弧长均匀重采样为 N=2048 个点（与画笔速度无关）
2. **闭合**：追加一段从末尾平滑回到起点的返回段，使周期信号连续（消除吉布斯振荡）
3. **离散傅里叶变换**：`X[k] = (1/N)Σ x[n]·e^(-2πikn/N)`，k 归一化到 [-N/2, N/2)
4. **截断**：按模长降序取前 M 个系数——即最佳 M 圆近似
5. **绘制**：每个系数画一个圆（圆心 = 前序圆链末端），链端即"画笔"，随时间推进描出轨迹
